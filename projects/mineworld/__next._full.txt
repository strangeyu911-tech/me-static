10:Te10,<h2>项目简介</h2>
<p>这是一个使用原生 Web 技术构建的 3D 体素游戏，玩家可以在无限生成的方块世界中探索、建造和冒险。游戏支持桌面端和移动端，提供流畅的游戏体验。</p>
<h3>在线体验</h3>
<p>访问 GitHub Pages: <a href="https://strangeyu911-tech.github.io/MineWorld/">https://strangeyu911-tech.github.io/MineWorld/</a></p>
<h2>功能特性</h2>
<ul>
<li>🎲 <strong>无限地形生成</strong> - 基于 Simplex 噪声算法生成自然地形</li>
<li>🏗️ <strong>方块建造系统</strong> - 支持多种方块类型的放置与破坏</li>
<li>🤖 <strong>AI 机器人</strong> - 侦察机器人和重型机器人在世界中巡逻</li>
<li>🎨 <strong>像素风格</strong> - 经典的 16x16 像素纹理设计</li>
<li>📱 <strong>跨平台支持</strong> - 桌面端键鼠操作 + 移动端触控操作</li>
</ul>
